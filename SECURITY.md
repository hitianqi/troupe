# Security

troupe runs coding agents in your terminals with the permissions you give
each role, so a bug that lets a role act outside its plan or its worktree is
a security bug.

## Reporting a vulnerability

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/hitianqi/troupe/security/advisories/new),
not in a public issue. Include what you ran, what happened, and the troupe,
tmux and agent versions.

You will get a reply within a week. Fixes go into the latest release only.
