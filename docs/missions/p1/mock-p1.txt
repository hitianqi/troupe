WHAT THE ENGINE CANNOT DRAW, AND WHAT IS DRAWN INSTEAD:
  - A Box border with a title in it ("╔═ ▦ MISSION p1 ═╗", "┌─ ≡ plan ─┐"), and the loop arrow under the boxes:
    the engine's Box has borders but no border title and no free lines. So the GRAPH is drawn as text lines
    from a character canvas (as OpenRig's own TUI does), with the same box set ╔═╗║╚╝ ┌─┐│└┘ ━━▶ ▲ └┘.
    What you see above is exactly what is drawn, cell for cell, in the colours above.
  - Strikethrough, bold and colour are the engine's own Text props: drawn as shown in the legend.
  - The TABLES are rows of Text with fixed column widths; the ━ rule and · separators are text lines.
  - The DETAIL sections are text lines in detail.js's format: "  ── TITLE ───" rules (chrome rule, bright bold title),
    "  label:" padded to 12 in dim grey with the value after it, wrapped lines hanging under the value column,
    ▪ for each duty bullet; ✓ green / ✗ red skills; "needs you" orange.

SIZES: docked at 110 columns the whole pane is 66 rows: header, GRAPH, TABLES, DETAIL (the dock scrolls when
shorter). Inline puts the header and the DETAIL sections first, then the TABLES (42 rows in all); the GRAPH shows
inline only when the engine gives it the rows for everything, and the pane asks for them when it opens (the
person's own size wins). With fewer rows, inline keeps the header and as much of DETAIL as fits, top down.
