# p2 mock: the troupe panel, split right inside the tmux window (o2)

Text mock for Tianqi, made by the code as it now stands (hooks/lines.ts), on
this mission's own plan. The panel draws the Phase 1 view with the rules
already approved for the pane:

- 90 columns or more: header, GRAPH, TABLES, DETAIL, as the p1 mock.
- Below 90 columns (the leftover "tables drop columns"): no TABLES; DETAIL
  carries each role's state on a line under the role.
- Below 48 columns: each DETAIL label takes its own line, the value under it.
- When the panel has fewer rows than the whole view, it draws the header and
  DETAIL only, with no GRAPH. This is the rule the inline pane already
  follows, and it keeps the panel from scrolling.

The split takes 40% of the window, at least 30 columns. In dev.b1's tile
(76x27) that makes the panel 30x27, and the transcript keeps 45 columns.

The messages /troupe answers in the transcript:
  /troupe docs/missions/p2   inside tmux:  troupe panel opened on the right (30 columns, pane %NNN).
                             again:        troupe panel already open (pane %NNN); now showing docs/missions/p2.
  /troupe close                            troupe panel closed.
  outside tmux:                            no tmux: showing the in-session pane
